# Browser Text to Speech Demo

This example demonstrates the core concept of AI voice generators: converting text into spoken audio. It uses the Web Speech API, a native browser feature, to perform text-to-speech (TTS) directly in the browser without any external dependencies or installations. Users can input text, select a language, and hear the text spoken aloud, simulating the functionality of modern AI voice generation tools.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser (Chrome, Edge, Firefox, Safari).
